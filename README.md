## 🚀 Featured Engineering Projects

### 🌪️ Cyclone AI — Spatiotemporal Tropical Cyclone Prediction & Decision Support
*Built for Smart India Hackathon (SIH)*  
**Stack:** Python, Deep Learning, Leaflet.js, React, REST API, Vercel  
**Links:** [Live Web Application](https://cyclone-ai-sih2026.vercel.app/) | [Repository](https://github.com/Utkarsh-96s/cyclone-ai)

* **Problem:** Tropical cyclone tracking requires digesting high-frequency multi-sensor satellite imagery and meteorological observations into rapid operational warnings for disaster response.
* **Solution:** An AI geospatial decision-support platform that ingests multi-source satellite streams for storm identification, intensity categorization, and forward trajectory tracking.
* **Key Engineering Work:**
  * Implemented an interactive geospatial map utilizing Leaflet.js rendering live storm center coordinates, wind velocity vectors, and projected cone-of-uncertainty zones.
  * Designed data parsing pipelines to feed spatiotemporal storm features into predictive inference endpoints with low latency.
  * Engineered a high-throughput, minimalist web dashboard deployed on Vercel for field accessibility during disaster assessment.

### 🧠 ShlokaMind — Bhagavad Gita NLP Recommendation & Semantic Search Engine
**Stack:** Python, NLP, TF-IDF, Scikit-learn, Cosine Similarity, React, Vercel  
**Links:** [Live Web Application](https://mlcseai.vercel.app/) | [Repository](https://github.com/Utkarsh-96s/shlokamind-nlp)

* **Problem:** Ancient philosophical literature contains relevant psychological and situational guidance, but archaic vocabulary makes contextual query retrieval difficult for modern users.
* **Solution:** An intelligent NLP recommendation platform that accepts natural-language user queries regarding emotional dilemmas (stress, duty, grief) and surfaces semantically aligned philosophical verses with contextual interpretations.
* **Key Engineering Work:**
  * Built an NLP preprocessing pipeline performing multi-lingual tokenization, custom stop-word pruning, and TF-IDF feature matrix vectorization.
  * Implemented high-performance cosine similarity ranking to score and retrieve top relevant verses with sub-second turnaround time.
  * Delivered a clean, responsive search client deployed on Vercel displaying original Sanskrit transcripts alongside structured situational translations.

### 🎙️ FinVoice — Automated Voice-Driven Financial Transaction Logger
**Stack:** Python, FastAPI, SpeechRecognition, PostgreSQL, Supabase, REST APIs  
**Links:** [Repository](https://github.com/Utkarsh-96s/finvoice-expense-logger)

* **Problem:** Manual mobile expense tracking suffers from high user friction and drop-off due to repetitive form filling.
* **Solution:** A voice-activated backend ingestion system that converts unstructured spoken input into structured, validated financial accounting records.
* **Key Engineering Work:**
  * Connected speech-to-text transcription logic with entity-extraction heuristics to accurately extract merchant names, currency values, and category classifications from natural speech.
  * Architected a normalized relational database schema in PostgreSQL / Supabase, applying B-tree indexes for rapid transactional aggregation and monthly analytics.
  * Built asynchronous REST endpoints using FastAPI for reliable payload handling, schema validation, and instant database persistence.

### 📚 Manhwa & Content Recommendation Engine
**Stack:** Python, Pandas, NumPy, Scikit-learn, Cosine Similarity, Flask  
**Links:** [Repository](https://github.com/Utkarsh-96s/manhwa-recommendation-engine)

* **Problem:** Finding relevant reading material across vast catalogs (2,000+ titles) requires multi-attribute matching rather than basic keyword lookups.
* **Solution:** A content-based recommendation engine evaluating composite genre matrices and synopsis vectors to suggest top-10 personalized matching titles.
* **Key Engineering Work:**
  * Cleaned and normalized tabular datasets of 2,000+ items using Pandas and NumPy, handling missing metadata and duplicate attribute strings.
  * Transformed synopsis text and categorical tags into sparse feature representations, applying Nearest Neighbors and cosine distance metrics for item similarity.
  * Wrapped the inference logic inside a modular Flask microservice delivering sub-second recommendations based on title or user-specified taste criteria.

### 🏥 Clinical Readmission & Deterioration Risk Engine
**Stack:** Python, Scikit-learn, XGBoost, Pandas, NumPy, Data Pipeline  
**Links:** [Repository](https://github.com/Utkarsh-96s/clinical-risk-engine)

* **Problem:** Early identification of hospital patient deterioration and unplanned readmission risks is critical to prevent adverse clinical outcomes.
* **Solution:** A supervised tabular machine learning pipeline that models multi-variable physiological markers to generate calibrated 30-day readmission risk scores.
* **Key Engineering Work:**
  * Implemented robust preprocessing workflows addressing high missing-rate medical features via median/KNN imputation and scaling.
  * Handled severe class imbalance using stratified cross-validation and probability threshold tuning to maximize recall without sacrificing precision.
  * Trained and compared baseline Logistic Regression with gradient boosted trees (XGBoost) for tabular classification performance.
